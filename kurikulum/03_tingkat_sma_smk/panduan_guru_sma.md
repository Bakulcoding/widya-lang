# 📕 Panduan Guru: Pembelajaran Widya-Lang Tingkat SMA / SMK (Kelas 10 - 12)

## 🎯 Tujuan Pembelajaran
1. Mempersiapkan siswa ke jenjang profesional industri perangkat lunak (*Software Engineering*).
2. Memahami konsep sistem tipe Hindley-Milner, Generics, Algebraic Data Types (ADT), dan Traits.
3. Menerapkan arsitektur database relasional (SQLite3 FFI), Web REST API, pengembangan Mobile, dan audit keamanan statis.
