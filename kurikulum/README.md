# 🎓 Silabus & Kurikulum Pembelajaran Widya-Lang (SD, SMP, SMA/SMK)

Selamat datang di **Kurikulum Pembelajaran Widya-Lang**. Kurikulum ini dirancang khusus untuk membangun fondasi berpikir komputasional (*computational thinking*), logika terstruktur, serta keahlian rekayasa perangkat lunak modern bagi peserta didik di Indonesia mulai dari jenjang Sekolah Dasar (SD), Sekolah Menengah Pertama (SMP), hingga Sekolah Menengah Atas / Kejuruan (SMA/SMK).

---

## 🎯 Visi & Keunggulan Pedagogis Widya-Lang
1. **Bahasa Ibu sebagai Jembatan Kognitif**: Menggunakan kata kunci bahasa Indonesia (`misal`, `jika`, `untuk`, `fungsi`, `cetak`) memudahkan siswa memahami konsep logika pemrograman tanpa terbentur kendala translasi bahasa asing di usia dini.
2. **Kesiapan Industri (Industry Ready)**: Sistem tipe statis Hindley-Milner, Pattern Matching, Generic, dan ekosistem modern memastikan bahwa apa yang dipelajari di jenjang atas setara dengan standar industri global (Rust, Swift, TypeScript, Go).
3. **Multi-Platform**: Pembelajaran mencakup logika dasar, aplikasi konsol, antarmuka web, hingga aplikasi mobile.

## 🟢 Jenjang 1: Sekolah Dasar (SD / Madrasah Ibtidaiyah)
*Target: Siswa Kelas 4 - 6*  
*Pendekatan: Belajar Sambil Bermain, Visual & Teks Ramah Anak*

### Modul & Materi Pembelajaran:
- **Modul 1: Mengenal Komputer & Sahabat Barumu (Widya-Lang)**
  - Pengenalan instruksi dan algoritma di kehidupan sehari-hari (resep masakan, langkah memakai seragam).
  - Perintah pertama: Menampilkan teks di layar (`cetak("Halo Dunia!")`).
- **Modul 2: Kotak Rahasia Penyimpan Informasi (Variabel & Tipe Dasar)**
  - Konsep variabel sebagai kotak bernama: `misal nama = "Budi"`, `misal umur = 10`.
  - Tipe data sederhana: Teks (Kata/Kalimat), Angka (Bulat & Desimal), dan Nilai Benar/Salah (Boolean).
- **Modul 3: Berhitung Cepat dengan Widya (Operator Matematika)**
  - Penjumlahan (`+`), Pengurangan (`-`), Perkalian (`*`), dan Pembagian (`/`).
  - Menghitung luas persegi panjang dan uang saku tabungan.
- **Modul 4: Robot yang Bisa Memilih (Percabangan Logika)**
  - Mengambil keputusan dengan `jika` dan `lainnya`.
  - Contoh: Menentukan kelulusan nilai, cuaca hujan atau cerah.
- **Modul 5: Robot yang Pantang Menyerah (Pengulangan Sederhana)**
  - Mengulang tugas dengan `untuk i dalam 1..10`.
  - Membuat pola angka, tabel perkalian sederhana.
- **Proyek Akhir SD**:
  - *Petualangan Teks Pilihanmu Sendiri (Interactive Story Book / Quiz Game).*

## 🟡 Jenjang 2: Sekolah Menengah Pertama (SMP / MTs)
*Target: Siswa Kelas 7 - 9*  
*Pendekatan: Logika Pemecahan Masalah, Struktur Kode Rapi, & Modularitas*

### Modul & Materi Pembelajaran:
- **Modul 1: Membagi Tugas dengan Sub-Program (Fungsi / Prosedur)**
  - Deklarasi fungsi dengan `fungsi nama_fungsi(parameter) -> Hasil`.
  - Parameter input dan pengembalian nilai (`kembalikan`).
  - *Scope* variabel (variabel lokal vs global).
- **Modul 2: Mengelola Banyak Data Sekaligus (Daftar / Larik / Array)**
  - Membuat dan mengakses koleksi data: `misal daftar_nilai = [85, 90, 78, 95]`.
  - Operasi dasar: Menambah elemen, mencari nilai maksimum/minimum, menghitung rata-rata.
- **Modul 3: Logika Bertingkat & Algoritma Pencarian**
  - Percabangan majemuk (`jika`, `kalau_tidak_jika`, `lainnya`).
  - Algoritma pencarian linier (*Linear Search*) dan pengurutan gelembung (*Bubble Sort*).
- **Modul 4: Interaksi Input Pengguna & File Sederhana**
  - Menerima masukan dari keyboard / Terminal.
  - Membaca dan menyimpan catatan ke file teks.
- **Modul 5: Pengenalan Pencocokan Pola (*Pattern Matching*)**
  - Menggantikan percabangan rumit dengan `cocokkan`.
- **Proyek Akhir SMP**:
  - *Sistem Manajemen Kasir Kantin Sekolah atau Game Tebak Angka & Kuis Trivia Interaktif.*

## 🔵 Jenjang 3: Sekolah Menengah Atas / Kejuruan (SMA/SMK)
*Target: Siswa Kelas 10 - 12 (Peminatan IPA/Informatika atau RPL/SIJA)*  
*Pendekatan: Standar Rekayasa Perangkat Lunak Industri, Tipe Statis, & Multi-Target*

### Modul & Materi Pembelajaran:
- **Modul 1: Sistem Tipe Kuat Hindley-Milner & Generic**
  - Memahami inferensi tipe statis dan keamanan kompilasi (*compile-time safety*).
  - Tipe Generic (`fungsi cetak_data<T>(nilai: T)`).
  - Penanganan nilai kosong tanpa Null Pointer Exception menggunakan Aljabar Tipe Data (`pilihan Opsi<T>`).
- **Modul 2: Struktur Data Kompleks & Paradigma Berorientasi Objek / Traits**
  - Deklarasi `struktur DataSiswa` dan `sifat (Trait)`.
  - Implementasi method dan enkapsulasi data.
- **Modul 3: Pengembangan Aplikasi Web & API**
  - Membangun REST API server backend dengan Widya-Lang.
  - Parsing dan serialisasi format JSON.
  - Konektivitas basis data relasional (SQLite3 FFI Engine).
- **Modul 4: Pengembangan Aplikasi Mobile (Android & iOS)**
  - Penggunaan perintah scaffold `widya mobile-init`.
  - Mendesain UI deklaratif dan mengelola state aplikasi.
- **Modul 5: Keamanan Aplikasi, Pengujian, & Toolchain Industri**
  - Melakukan audit keamanan kode dengan `widya audit` (pencegahan SQLi, Secret Leak, XSS).
  - Penulisan Unit Test otomatis (`widya test`).
  - Manajemen paket dan dependensi dengan `widya wpm`.
- **Proyek Akhir SMA/SMK**:
  - *Aplikasi Presensi Sekolah Berbasis Mobile / Web API dengan Database SQLite & Audit Keamanan.*
