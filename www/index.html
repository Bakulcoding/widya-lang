Hindley-Milner Type System

Inferensi tipe statis tanpa boilerplate anotasi manual, monomorphization generics, dan pattern matching berekspresi tinggi.

⚡

Full Self-Hosting Compiler

Kompiler Widya ditulis 100% menggunakan bahasa Widya (Stage-0 ke Stage-2 deterministik biner mandiri).

🔒

AST Security Linter Bawaan

Pencegahan otomatis terhadap SQL Injection, XSS Payload, dan kebocoran Secret/API Keys langsung saat kompilasi (`widya audit`).

📱

Mobile Engine (Android & iOS)

Generator proyek otomatis untuk Android APK/AAB dan iOS Xcode Project tanpa perlu framework pihak ketiga yang berat.

🌐

Multi-Target Codegen

Dukungan emisi biner Native, WebAssembly (WASM), WebGPU Compute Shaders (WGSL), dan kernel observability Linux eBPF.

🛠️

All-in-One Developer Toolchain

LSP Language Server, DAP Visual Debugger, Ekstensi Resmi VS Code, Memory Profiler, dan WPM Package Manager dengan Lockfile.
